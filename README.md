# SolAR
Este repositorio es basado en la energía solar. 
Toca puntos de que es, como los profesionales trabajan, los puntos fuertes de la tecnología para el usuario y cual será el porvenir de esta.
Igualmente el enfoque es informar y educar sobre la materia, tanto en ahorro energetico como economico y lo legal, este último será según el lugar donde se realizará el proyecto.

Actualmente, cuando se crea este doc, nos ubicamos desde Argentina, Córdoba y tomamos a ésta como una referencia para inbuirnos al tema de la Energia Solar.
