# SolAR
Este repositorio está basado en la energía solar. 
Toca temas como: 
  * El desarrollo de un proyecto desde el punto de vista de un profesional.
  * Los puntos fuertes de la tecnología para el usuario y cual será el porvenir de esta.
  * Informar y educar sobre la materia tanto en ahorro energetico como economico y lo legal, este último será según el lugar donde se realizaria el proyecto.
  * Que debemos tener en cuenta antes de invertir en generar energia solar.
  * Cuales son las preguntas mas comunes y las mas importantes.
  * A quien va dirigida.
  * Un analisis detallado de cuanto se puede ahorrar según el consumo.
  * Tips legales (Según el lugar).

Actualmente, cuando se crea este doc, nos ubicamos desde Argentina, Córdoba y tomamos a ésta como una referencia para inbuirnos al tema de la Energia Solar.

Aclaración: Los PDF provistos son realizados por Gamma.app un sitio que ayuda a crear estas presentaciones mas completas donde yo creo el contenido personalmente, lo organizo y lo plasmo para que el modelo de lenguaje cree un diseño en formato presentación. Aunque elegí uno particular agradable y práctico, seguramente lo corregiré para mejor en el futuro.
